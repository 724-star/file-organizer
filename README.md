# 文件整理工具

一个 Windows 桌面文件整理工具，用 Python + Tkinter 开发，图形界面，中文。
核心目标：**一目了然看清每个文件**，并能一键自动整理桌面零散文件。

## 功能一览

### 三栏布局
- **左栏 · 文件夹目录树**：默认定位到桌面，点击可切换任意文件夹，展开子目录。
- **中栏 · 文件列表**：每行显示文件图标、文件名、类型、大小、修改时间；点表头可按名称/类型/大小/时间排序；顶部搜索框可按文件名过滤；按住 Ctrl 可多选。
- **右栏 · 文件预览**：选中文件立即预览——
  - 图片：显示缩略图；
  - 文本文件（txt/py/html/js 等）：显示前 50 行内容；
  - 其他类型：显示完整路径、后缀、大小、创建时间等基础信息。

### 自动整理
- 内置分类规则：图片 / 文档 / 视频 / 压缩包 / 代码 / 其他。
- 点「预览整理方案」：先在列表里标清楚每个文件会被移动到哪个文件夹，**不直接执行**。
- 确认后，才自动新建分类文件夹、移动对应文件。
- 支持「撤销上次整理」，把文件移回原位。

### 手动操作
- 勾选多个文件，可批量移动到指定文件夹、批量重命名、删除。
- 所有删除、移动操作都会弹出确认窗口（删除会二次确认）。

### 安全设计
- 所有文件操作「先规划、后执行」，绝不私自删改文件。
- 移动遇到同名文件会自动加序号，绝不覆盖。
- 删除是永久删除（不进回收站），因此有二次强确认。

## 环境要求

- Windows 系统
- Python 3.7 及以上（自带 Tkinter）

## 安装步骤

1. 确认已安装 Python（命令行输入 `python --version` 能显示版本即可）。
2. 安装依赖（只有 Pillow 一个库）：

```bash
pip install Pillow
```

> 如果已经装过 Pillow，可以跳过这一步。

## 启动命令

进入本工具所在目录，然后运行：

```bash
python main.py
```

或者直接双击 `main.py` 文件（如果系统关联了 Python）。

## 使用说明

1. 启动后，左栏默认显示「桌面」，中栏列出桌面上的文件。
2. **看文件**：点中间的文件，右边立刻预览。
3. **整理桌面**：点顶部「预览整理方案」→ 查看每个文件会去哪 → 点「执行整理」→ 再确认一次，就自动分类好了。
4. **反悔**：点「撤销上次整理」把文件移回原位。
5. **手动整理**：按住 Ctrl 勾选多个文件，再用「移动到…」「批量重命名」「删除」。
6. **找文件**：在右上角搜索框输入文件名关键字，列表会实时过滤。

## 项目文件说明

| 文件 | 作用 |
|---|---|
| `main.py` | 程序入口 |
| `config.py` | 分类规则、图标、常量（想改分类就改这里） |
| `file_ops.py` | 文件操作核心逻辑（扫描/分类/整理/撤销） |
| `app.py` | 主窗口（三栏布局 + 按钮） |
| `preview.py` | 右侧预览面板 |
| `requirements.txt` | 依赖清单 |
| `README.md` | 本说明 |

## 常见问题

- **图片不显示缩略图**：说明没装 Pillow，运行 `pip install Pillow` 后重启即可。
- **中文乱码**：本工具已兼容 UTF-8 和 GBK 编码，一般不会乱码。
- **想改分类规则**：编辑 `config.py` 里的 `CATEGORY_RULES` 即可，不用改其他文件。
